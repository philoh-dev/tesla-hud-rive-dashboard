- `park.png`: Recolor only painted body/metal and mirror caps. Preserve the

  or pinched front. Keep the existing factory trunk lip, no added spoiler.

Both prompts require one whole centered car with a small transparent margin,
no clipping, genuine transparent alpha, no floor/shadow/environment/dealer
plate, labels or watermark, and the same polished dashboard-render style.
These are illustrative sprites, not official Tesla renders.
